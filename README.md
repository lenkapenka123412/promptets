# ПРОМПТЕЦ v0.2

**Генератор самых действенных бесполезных промптов.** Юмористический одностраничный сайт, готовый для локального запуска и статического хостинга.

## Быстрый запуск

1. Распакуйте ZIP полностью в одну папку. **Не открывайте `index.html` из окна просмотра ZIP**.
2. Дважды щёлкните `index.html`. Он открывается без локального сервера и без установки зависимостей.
3. Выберите уровень раздражения и нажмите **«КРУТАНУТЬ ПРОМПТЕЦ»**.
4. Нажмите **«Скачать карточку PNG»**: браузер создаст вертикальное изображение 1080×1920. Кнопка «Поделиться» откроет системное меню при поддержке мобильного браузера. Прямое размещение в Instagram не гарантируется.

## Как редактировать фразы

- Откройте `prompts_editor.xlsx` или `prompts.csv`.
- Основные колонки: `phrase` (фраза), `category` (категория), `level` (1–3), `swear` (`Да`/`Нет`), `recommendation` (забавная рекомендация), `status` (`На проверку`, `Одобрено`, `Доработать`, `Удалить`). `id` оставляйте уникальным.
- Статус `Удалить` исключает фразу из рулетки. Другие статусы показываются в прототипе до завершения редакторского отбора.
- Для **временного предпросмотра**: экспортируйте Excel-лист как CSV UTF-8, на сайте нажмите **«Загрузить CSV / JSON»**. Импорт не меняет опубликованные файлы и пропадает при обновлении страницы.
- Для **постоянного обновления**: положите обновлённый CSV в папку проекта и запустите `python tools/sync_prompts.py prompts.csv`. Это синхронизирует `prompts.json`, `prompts-data.js` и `prompts.csv`. После этого отправьте изменения на GitHub. Vercel (если подключён через репозиторий) обновит сайт.

## Структура проекта

```text
index.html             — разметка сайта
styles.css             — адаптивный дизайн
app.js                 — рулетка, фильтры, PNG, копирование, импорт
prompts-data.js        — база, доступная без сервера (генерируется автоматически)
prompts.json           — структурированная база
prompts.csv            — таблица для импорта в Excel / Google Sheets
prompts_editor.xlsx    — редакторский Excel-файл
favicon.svg            — иконка сайта
vercel.json            — настройки статического размещения
TZ_FOR_CODEX.md        — подробное техническое задание для Codex
tools/sync_prompts.py  — синхронизация CSV/JSON с сайтом
```

## Публикация на GitHub и Vercel

1. Создайте **новый** репозиторий `promptets` на своём GitHub. Сохраняйте все файлы в **корне**, а не в подпапке.
2. Загрузите содержимое архива в репозиторий (с ZIP нужно предварительно распаковать).
3. В Vercel: **Add New → Project → Import Git Repository → promptets**.
4. Framework Preset: **Other**, Root Directory: `.`, Build Command: пусто, Output Directory: пусто. Нажмите **Deploy**.
5. Откройте **фактическую** ссылку, которую выдаст Vercel, и проверьте рулетку, кнопки, мобильную версию.

**Важно:** GitHub и Vercel этим архивом не подключаются автоматически. Не выдавайте предполагаемый адрес за действительный.

## Технические и редакторские ограничения

- База содержит 300 авторских редакторских заготовок (включая 3 фразы, отмеченные как «Фраза пользователя»), а **не 300 подтверждённых интернет-цитат**. Все строки помечены «На проверку».
- Для Instagram Stories нет надёжного стандартного веб-API прямой публикации из обычного сайта. Возможен системный Share Sheet или ручное добавление скачанной PNG.
- Никаких внешних API, серверов, аналитики, регистрации и токенов.
- Результат работы рулетки — юмор, а не совет по промпт-инжинирингу.
- Не использовать Google Sheets/Excel файл как непосредственную базу живого сайта без отдельной серверной интеграции.
