# Техническое задание: ПРОМПТЕЦ (релиз v0.2 → публикация)

## 1. Цель

Создать и опубликовать забавный, но визуально солидный одностраничный сайт «ПРОМПТЕЦ»: **«Последний аргумент в разговоре с искусственным интеллектом»**. Он выдаёт случайные абсурдные «промпты» в ответ на нажатие кнопки. Для пользователя это мини-игра и источник карточек для сторис, **не настоящий помощник по созданию промптов**.

Пользователь предоставляет ZIP этого проекта. Codex должен взять из архива исходники, при необходимости переработать их, протестировать и **самостоятельно опубликовать в новом репозитории GitHub и на Vercel**, если имеются необходимые доступы. Не заменять готовый проект пустым лендингом. Не трогать другие репозитории. Если для создания репозитория или входа в Vercel требуется пользовательская авторизация, запросить только нужное действие, без ручной пересылки файлов.

## 2. Исходная комплектация

- `index.html`, `styles.css`, `app.js`, `favicon.svg`: работоспособный интерфейс без фреймворков.
- `prompts.json` и `prompts-data.js`: 300 записей, одинаковая база в двух форматах. `prompts-data.js` нужен для **открытия HTML двойным кликом без локального сервера**, поскольку `fetch()` из `file://` ненадёжен.
- `prompts.csv`, `prompts_editor.xlsx`: рабочая редакторская база.
- `tools/sync_prompts.py`: преобразование отредактированного CSV/JSON в файлы сайта.
- `README.md`: локальный запуск и деплой.

## 3. Целевая аудитория и тональность

Маркетологи, дизайнеры, разработчики, продюсеры, все люди, которые хоть раз в отчаянии говорили нейросети «сделай нормально!». Стиль: серьёзный интерфейс псевдонаучного инструмента с самоиронией, без инфобизнесовой глянцевости. Разрешены резкие фразы и мат; обязателен переключатель «Без мата, я на работе». Не добавлять оскорбления конкретных людей или защищённых групп.

## 4. Визуальная концепция

- Тёмный графитовый фон `#111117`, жёлтый `#F7DB45`, приглушённый розовый `#F18394`, молочно-белая карточка результата.
- Крупная типографика «СДЕЛАЙ НОРМАЛЬНО!»; логотип «ПРОМПТЕЦ.»; ироничные псевдотехнические подписи.
- Интерфейс напоминает дорогой AI-сервис и немного лабораторный прибор: статус `READY/PROCESSING`, индикаторы, рамки, нумерация шагов.
- **Не делать барабан/колесо.** Нужна вертикальная рулетка из трёх строк с акцентом на центральной: фразы быстро сменяют друг друга, замедляются и останавливаются.
- Мобильный экран в приоритете: кнопки крупные, основной текст читаем, без горизонтального скролла.

## 5. Пользовательский сценарий

1. Открывает сайт, видит большую шутливую вводную и блок генератора.
2. Выбирает «Сюрприз», «Держусь», «Бесит» или «Я ору». Последние три соответствуют уровням 1, 2, 3. «Сюрприз» выбирает все уровни.
3. По желанию включается режим «Без мата». Фильтрация проходит **до** выбора результата.
4. Нажимает большую жёлтую кнопку «КРУТАНУТЬ ПРОМПТЕЦ».
5. Центральная строка сменяется примерно 2–4 секунды, постепенно замедляясь; сбоку приглушённые предыдущая и следующая строки.
6. Выпадает **случайная** фраза из подходящей выборки; пользователь видит «Ваш промпт дня», название категории, индекс отчаяния от 0 до 100 и рекомендацию по применению.
7. Пользователь может повторить розыгрыш, скопировать фразу, скачать PNG-карточку 1080×1920 либо попробовать «Поделиться в сторис».

## 6. Функциональные требования

### Рулетка и фильтры

- Уровень раздражения и опция без мата должны менять пул доступных фраз и счётчик.
- Выбор не должен повторять недавние ~10–12 результатов, если в выборке достаточно альтернатив.
- Пока проигрывается анимация, второй запуск запрещён. Должна быть обработка пустой выборки.
- При `prefers-reduced-motion` анимация значительно сокращается или отключается.
- Не использовать нейросетевой API. Вся логика в клиентском JS.

### База

Каждая запись: `id` (стабильный уникальный), `phrase` (текст), `category`, `level` (`1|2|3`), `swear` (`Да|Нет`), `recommendation`, `status`, `favorite`, `origin`, `source_url`, `editor_note`. Уровень и мат определяются данными, **не** автоматическими догадками из текста. Фразы `status=Удалить/Отклонено` исключаются из рулетки. Файлы CSV/JSON с UTF-8 поддерживаются в редакторском импорте; `;` и `,` как CSV-разделители. Отслеживать отсутствие `phrase`, некорректные уровни и неуникальные ID при синхронизации для продакшна.

Важное редакторское правило: **300 фраз сейчас имеют статус «На проверку»**. Не утверждать, что это 300 реальных цитат из интернета. Пользователь сама проведёт отбор. Отделять авторские заготовки от подтверждённых публичных цитат, которые добавятся позднее с ссылкой `source_url`.

### Карточка сторис

- Canvas PNG **1080×1920 (9:16)**, с названием сайта, цитатой, индексом отчаяния, рекомендацией и читаемым брендингом.
- Длинные фразы аккуратно переносятся, не выходя за пределы карточки.
- «Скачать PNG» должно работать в обычных современных браузерах.
- «Поделиться в сторис»: применить Web Share API с `File` там, где поддерживается. Если API отсутствует, **скачать PNG и объяснить, как загрузить вручную**.
- Не обещать прямую автоматическую публикацию в Instagram Stories: стандартное веб-приложение не может гарантированно сделать это без дополнительных платформенных механизмов и разрешений.

### UX, безопасность, доступность

- Навигация с клавиатуры, видимый фокус, ARIA-состояния, метки для кнопок, контрастность.
- Рабочие `button`-действия; понятные сообщения об ошибках/успехах, без фальшивого «опубликовано».
- Без трекеров, регистрации, запросов конфиденциальной информации, секретов и внешних зависимостей.
- Публичная версия должна открываться по HTTPS и по адресу Vercel, который реально возвращён сервисом.

## 7. Редакторский интерфейс и обновление данных

- На странице оставить загрузку CSV или JSON **для временного предпросмотра** и кнопку экспорта JSON.
- Пользователь меняет Excel, сохраняет CSV UTF-8, загружает его на страницу и проверяет шутки.
- Для постоянного изменения публичного сайта через Codex запускать `python tools/sync_prompts.py prompts.csv` и делать git commit. Поддерживать `prompts-data.js`, чтобы сайт работал локально из файла.
- Не показывать «сохранено на сервер» при локальном импорте: импорт живёт только в открытой вкладке.

## 8. Стек и структура

**HTML5, CSS3, JavaScript ES2020+, Canvas 2D** без npm, React, внешних шрифтов или API. Можно оставить существующий стек. Структура каталогов из раздела 2; точка входа `index.html` в корне. Не требуются build-команды и Node-сервер. Для предпросмотра допустимо `python -m http.server 8000`, но локальное двойное открытие тоже должно работать.

## 9. Тесты и критерии готовности

Проверить на десктопе (1440×900) и мобильных разрешениях (390×844, 360×800):

- страница без переполнений и ошибок JavaScript;
- есть **300** строк, число меняется после редакторского импорта;
- каждый из 3 уровней и «Сюрприз» выдаёт записи из нужного пула;
- при фильтре «Без мата» ни одна помеченная `swear=Да` фраза не выпадает;
- многократное нажатие не вызывает наложения анимаций;
- с выбранной фразой работают кнопки копирования, скачивания карточки и повторного розыгрыша;
- скачанная PNG имеет **ровно 1080×1920**, текст не обрезан;
- редакторский импорт CSV и JSON работает, удалённые фразы исключаются;
- кодирование кириллицы исправно;
- режим сниженной анимации работает;
- проверено отсутствие `fetch('prompts.json')` при локальном запуске `file://`.

## 10. GitHub и Vercel

1. Создать **новый публичный** репозиторий на GitHub пользователя с именем `promptets` (если имя занято, использовать `promptets-roulette`), не модифицируя чужие и существующие проекты.
2. Разместить полный исходный код в корне; добавить `README.md`, редакторские форматы, ТЗ. Убедиться, что `index.html` не вложен в лишнюю папку.
3. Подключить репозиторий к Vercel как статический сайт: Framework Preset `Other`, Root Directory `.`. Без build command, серверных функций и секретов.
4. Выполнить production deploy и дождаться статуса `Ready`.
5. Открыть реальный публичный URL и проверить ключевой сценарий; прислать **проверенный** HTTPS-адрес сайта и ссылку на GitHub.
6. Если у Codex нет разрешения на создание репозитория или Vercel не авторизован, обозначить точный недостающий шаг и продолжить после подтверждения. Не выдумывать ссылку `promptets.vercel.app`, пока она не получена от платформы.

## 11. Чего не делать

- Не заменять текстовую рулетку колесом.
- Не подключать платные AI API ради случайного выбора строки.
- Не обещать «100% рабочий промпт» без очевидной сатирической рамки.
- Не копировать реальные цитаты без указания происхождения и ссылки.
- Не складывать исходники в архив, который сам же требует скачивания с другого компьютера.
- Не тратить время на аккаунты, платежи, сложную CMS: первая версия остаётся одностраничной игрушкой.
